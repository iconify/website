## New API servers {#new-api}

Iconify API server infrastructure has been re-built.

Changes:

- New faster servers with twice more memory.
- Stricter limits for usage. Apps that abuse API will now find themselves rate limited.

### New limits

Iconify API is not a free hosting service to link to.

Its main purpose is to load icons on demand for icon components. Any other use is a bonus that should not be abused.

Some apps have abused API servers by flooding API with hundreds of queries per second. That is not acceptable!

### Solution

If your app was hit with usage limit, you are doing it wrong.

Solutions:

- Fix your app. Load only data you need, not everything.
- Host your own API instance. API is open source, now it has [a deployment script](/docs/api/hosting-js/deployment.md), so you can create your own API instance without being familiar with server management.
